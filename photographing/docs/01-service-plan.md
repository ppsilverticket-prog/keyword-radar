# 포토그래핑 서비스 플랜 v1.0

작성일: 2026-09-24 · 상태: 초안 (검증 단계 전)

## 1. 서비스 정의

포토그래핑은 사진을 찍는 사람들이 **함께 출사를 나가고, 비슷한 사람끼리 모여 이야기하고, 나에게 맞는 사진 정보를 얻는** 모임 기반 사진 커뮤니티 앱입니다.

인스타그램이 "사진을 보여주는 곳"이라면, 포토그래핑은 **"사진 찍는 사람을 만나는 곳"**입니다.

| 축 | 내용 | 사용자가 얻는 것 |
|---|---|---|
| ① 자율 출사 모임 | 누구나 모임을 열고 참여하는 소모임 방식 | 같이 찍을 사람, 새로운 장소 |
| ② 유형별 커뮤니티 | 아마추어, 상업 작가, 학생 등 활동 유형별 공간 | 수준과 관심사가 맞는 대화 |
| ③ 연령대별 정보 | 세대에 맞춘 입문 가이드, 장비 추천, 활동 정보 | 나에게 맞는 정보 |

## 2. 사용자 구조

가입할 때 **활동 유형**과 **연령대** 두 가지를 설정하고, 이 조합으로 콘텐츠와 모임을 추천합니다.

**활동 유형**

- 🌱 입문자: 폰카나 카메라 입문 1년 미만
- 📷 아마추어: 취미로 꾸준히 촬영
- 🎓 학생/전공자: 사진 전공, 동아리
- 💼 상업 작가: 웨딩, 프로필, 제품, 스냅 등으로 수익 활동. 포트폴리오 인증 후 배지 부여

**연령대**: 10대 · 20대 · 30대 · 40대 · 50대 이상

> ⚠️ 미성년자 정책은 초기에 꼭 정해야 합니다. 오프라인 모임 앱에서 미성년자와 성인이 만나는 구조는 안전 사고 위험이 크고, 만 14세 미만은 가입 시 보호자 동의가 필요합니다. **MVP는 만 19세 이상 가입으로 시작**하고, 10대 전용 공간은 안전장치를 갖춘 뒤 추가합니다.

## 3. 핵심 기능 상세

### ① 자율 출사 모임

- 모임 개설: 제목, 장소(지도), 날짜·시간, 인원, 난이도, 참가비(무료/실비), 대상(유형·연령대 제한 가능)
- 모임 유형: 일회성 번개 출사 / 정기 모임(크루)
- 참여 방식: 바로 참여 또는 모임장 승인
- 모임 채팅방: 참여 확정자만 입장
- 출사 후 앨범: 모임에서 찍은 사진을 한곳에 모아 공유
- 후기와 신뢰도: 참석 여부, 매너 평가 → 프로필에 신뢰 점수 표시 (노쇼 방지)

### ② 유형별 커뮤니티

- 라운지: 입문자, 아마추어, 학생, 상업 작가별 게시판
- 주제 채널: 풍경, 인물, 스냅, 필름, 스트리트, 야경 등
- 피드백 요청 게시판: 사진을 올리고 구체적인 크리틱을 받는 공간
- 상업 작가 전용: 촬영 단가·계약 노하우, 장비 투자, 세금 등 실무 정보 (인증 작가만 글 작성)
- 질문 답변: 입문자 질문에 경험자가 답하는 Q&A

### ③ 연령대별 정보

- 세대별 큐레이션 탭: 운영팀이 만든 가이드 + 커뮤니티 인기글
  - 20대: 가성비 입문 장비, 폰카 활용법, 스냅 촬영
  - 30~40대: 아이·가족 사진, 여행 사진, 장비 업그레이드
  - 50대 이상: 풍경·야생화 출사지, 기초 보정 쉽게 배우기, 큰 글씨 모드
- 초기에는 태그와 추천으로 구현하고, 별도 시스템은 나중에 만듭니다 (개발량 절감)

## 5. MVP 범위

전부 만들면 6개월 이상 걸립니다. MVP는 **"모임이 열리고, 사람들이 다시 오는지"** 검증하는 것에 집중합니다.

**✅ MVP 포함**

- 가입/로그인(카카오·애플) + 휴대폰 본인인증(오프라인 모임 안전용, 성인 확인)
- 활동 유형·연령대·관심 장르·지역 설정
- 출사 모임 개설, 탐색, 참여, 모임 채팅
- 유형별 라운지 게시판 + 피드백 게시판
- 사진 업로드(EXIF 표시, GPS 자동 제거), 댓글, 좋아요, 팔로우
- 프로필, 포트폴리오 그리드
- 신고·차단, 모임 후기(간단한 매너 평가)

**⏳ MVP 이후 (2단계)**

- 상업 작가 포트폴리오 인증 배지
- 연령대별 큐레이션 탭 고도화
- 출사 후 공유 앨범, 정기 크루 기능
- 주간 사진 챌린지, 푸시 알림 세분화

**🔮 장기 (3단계)**

- 촬영 의뢰·작가 매칭, 유료 모임 결제, 출사지 데이터베이스, 10대 전용 공간

## 6. 기술 스택

| 영역 | 추천 | 이유 |
|---|---|---|
| 앱 | Flutter 또는 React Native | iOS와 안드로이드 동시 개발 |
| 백엔드 | Supabase (또는 Firebase) | 인증, DB, 실시간 기능, 스토리지 일체형 |
| 채팅 | Supabase Realtime (규모가 커지면 Sendbird 등 전문 솔루션) | 모임 채팅 |
| 지도 | 카카오맵 또는 네이버지도 API | 국내 장소 검색 품질 |
| 이미지 | Cloudflare Images 등 이미지 CDN | 사진 앱 비용의 핵심인 트래픽 관리 |
| 본인인증 | PASS 등 국내 본인인증 서비스 | 성인 확인, 노쇼·악용 방지 |
| 분석 | Amplitude 또는 Mixpanel | 지표 추적 |

## 7. 일정 (약 16주)

| 주차 | 단계 | 주요 작업 |
|---|---|---|
| 1~2 | 검증 | 출사 모임 운영자·참여자 15명 인터뷰, 경쟁 서비스 분석(문토, 네이버 밴드·카페 사진 동호회 등), 상표·앱 이름 중복 확인 |
| 3~5 | 기획·디자인 | 사용자 흐름, 와이어프레임, 브랜드(로고·컬러), 핵심 화면 UI, 운영정책·약관 초안 |
| 6~12 | 개발 | 6~7주: 인증·온보딩 / 8~9주: 모임 기능·지도·채팅 / 10~11주: 커뮤니티·업로드 / 12주: 신고·후기·관리자 페이지 |
| 13~14 | 클로즈드 베타 | 서울 한정, 초대 사용자 100명, 실제 출사 모임 10회 이상 진행 |
| 15~16 | 출시 | 버그 수정, 앱스토어 심사, 소프트 런칭 |

병행 작업: 1주차부터 포토그래핑 SNS 계정을 운영하고, 사전 신청자와 창립 모임장을 모집합니다.

## 8. 초기 사용자 확보 전략

모임 앱의 성패는 **"열려 있는 모임이 있느냐"**에 달려 있습니다.

- **지역 집중**: 처음에는 서울(예: 성수, 을지로, 한강권)만 운영합니다. 모임이 여러 지역에 흩어지면 어디에도 모임이 없어 보입니다.
- **창립 모임장 20명**: 기존 사진 동호회 운영자나 출사 인솔 경험자를 섭외해 매주 모임을 열도록 지원합니다 (배지, 수수료 면제 등 혜택).
- **공식 출사 이벤트**: 운영팀이 매주 1~2회 공식 모임을 직접 엽니다.
- **대학 사진 동아리 제휴**: 20대 사용자와 콘텐츠 공급원을 동시에 확보합니다.
- **상업 작가 초대**: 소수의 작가를 초청해 "현직 작가와 함께하는 출사" 같은 특별 모임을 엽니다. 아마추어 유입에 효과가 큽니다.

## 9. 안전과 운영 정책

오프라인 모임 서비스이므로 반드시 필요합니다.

- 본인인증 필수, 모임 참여 이력과 신뢰도 공개
- 모임 중 문제 발생 시 긴급 신고 버튼
- 인물 촬영 시 초상권 동의 안내, 도촬 금지 정책
- 사진 도용 신고 절차(저작권)
- 위치 기반 기능을 쓰면 위치기반서비스사업자 신고 필요 여부를 확인
- 개인정보처리방침, 이용약관, 커뮤니티 가이드라인

## 11. 성공 지표 (베타~출시 3개월)

- 주간 개설 모임 수: 서울 기준 주 20개 이상
- 모임 참석률: 신청 대비 실제 참석 80% 이상 (노쇼율 관리)
- 재참여율: 첫 모임 참석자 중 한 달 안에 다시 참석한 비율 30% 이상
- 커뮤니티 활성도: 피드백 요청 글 중 답변이 달린 비율 70% 이상
- 주간 재방문율(D7): 25% 이상

## 12. 예상 비용 (대략)

- **개발**: 외주 시 모임, 채팅, 커뮤니티, 본인인증이 포함되어 단순 사진 피드 MVP보다 범위가 큽니다. 수천만 원대 후반까지 예상하고 여러 업체의 견적을 비교하세요. 직접 개발하면 인건비만 듭니다.
- **운영**: 서버·이미지 CDN은 초기 월 수십만 원 수준, 본인인증은 건당 과금
- **기타**: 앱스토어 계정, 상표 출원, 디자인, 초기 모임 운영비(공식 출사 이벤트)
