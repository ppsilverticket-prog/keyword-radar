# "포토그래핑" 이름 확인

작성일: 2026-09-24 · 상태: 1차 웹 조사 완료, 공식 조회 전

## 1. 결론 요약

- 웹 검색 기준으로 **"포토그래핑"이라는 이름의 앱이나 서비스는 확인되지 않았습니다.**
- 다만 **"포토그레이(PhotoGray)"** 라는 활발한 사진 브랜드(무인 포토부스 프랜차이즈, 구글 플레이에 앱 등록)가 있어 발음·표기가 비슷합니다. 상표 심사에서 유사 판단을 받을 가능성을 확인해야 합니다.
- "포토그래핑"은 영어 photographing의 음역이라 **식별력이 약한 이름**으로 판단될 수 있습니다. 사진 관련 업종(앱, 커뮤니티 서비스)에서 단독 문자 상표로는 등록이 거절되거나 권리 범위가 좁을 수 있습니다. 로고와 결합한 도형 상표 출원, 또는 식별력 있는 부기(예: "포토그래핑 클럽")를 함께 검토하세요.
- 아래 공식 조회 3가지는 직접 해야 합니다. 이 세션에서는 자동 조회가 불가능했습니다.

## 2. 조사한 것과 결과

| 항목 | 방법 | 결과 |

| 상표·브랜드 | 웹 검색 ("포토그래핑" 상표/브랜드/스튜디오) | 동일 상표 확인 안 됨. 일반 촬영 스튜디오 결과만 나옴 |
| 경쟁 앱 | 검색 결과에서 파악 | 사진 판(작품 공유·크리틱), 트윅(AI 사진 커뮤니티), 포토이즘·포토그레이(포토부스) |

## 3. 직접 확인할 것 (체크리스트)

### 3-1. 상표 (KIPRIS)

특허정보검색서비스 http://www.kipris.or.kr 에서 "상표" 검색.

- [ ] 검색어: `포토그래핑`, `PHOTOGRAPHING`, `포토그래핑*` (와일드카드)
- [ ] 유사 검색어: `포토그레이`, `포토그래피`, `PHOTOGRAPHY`
- [ ] 확인할 상품 분류(니스 분류)
  - 09류: 모바일 앱, 다운로드 가능한 소프트웨어
  - 35류: 온라인 광고, 커뮤니티 플랫폼 운영
  - 38류: 온라인 채팅·메시지 전송, 온라인 커뮤니티 제공
  - 41류: 사진 촬영 교육, 워크숍, 모임 운영
  - 42류: SaaS, 플랫폼 제공
  - 45류: 온라인 소셜 네트워킹 서비스
- [ ] 결과 기록: 동일/유사 상표가 있으면 출원번호, 권리자, 지정상품을 아래 표에 적기

## 4. 이름 리스크와 대안

| 리스크 | 설명 | 대응 |
|---|---|---|
| 식별력 약함 | "포토그래핑"은 사진 촬영을 뜻하는 일반 단어의 음역 | 로고 결합 상표 출원, 슬로건 병기 ("포토그래핑 - 사진 찍는 사람을 만나는 곳") |
| 포토그레이와 유사 | 앞 4글자 동일, 사진 업종 동일 | KIPRIS에서 포토그레이의 지정상품 확인. 09·38·45류에 등록돼 있으면 변리사 상담 |
| 검색 노출 | "포토그래핑" 검색 시 일반 촬영 정보와 섞임 | 브랜드 검색어를 "포토그래핑 앱"으로 통일, SNS 계정명에 `app`/`kr` 부기 |
