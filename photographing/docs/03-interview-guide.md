# 검증 인터뷰 가이드 (1~2주차)

작성일: 2026-09-24 · 대상: 출사 모임 운영자·참여자, 상업 작가 · 목표 15명

## 1. 인터뷰 목적

플랜의 핵심 가정 3가지를 확인합니다. 인터뷰가 끝나면 각 가정에 대해 "맞다 / 틀리다 / 조건부"로 결론을 냅니다.

| # | 가정 | 확인 방법 |
|---|---|---|
| A | 사진 찍는 사람들은 **같이 찍을 사람과 장소**를 찾는 데 불편을 겪고 있다 | 현재 어떻게 출사 동행을 구하는지, 그 과정에서 포기한 경험이 있는지 |
| B | 모임에 나갈 때 **상대의 실력·유형·연령대**를 미리 알고 싶어 한다 | 모임 참여를 망설인 이유, 실제로 나갔을 때 불편했던 점 |
| C | 좋아요가 아니라 **구체적인 피드백**을 받을 곳이 없다 | 사진을 올리는 곳과 거기서 받는 반응, 피드백을 받으려고 해본 시도 |

## 2. 모집

### 대상 구성 (총 15명)

| 그룹 | 인원 | 찾는 곳 |
|---|---|---|
| 출사 모임 운영자 (동호회장, 인솔자) | 5명 | 네이버 카페·밴드 사진 동호회, 문토·소모임 앱의 사진 모임, 대학 사진 동아리 회장 |
| 출사 모임 참여자 (최근 6개월 내 1회 이상) | 7명 | 위 모임의 참여자, 인스타그램 #출사 해시태그, 지인 소개 |
| 상업 작가 (스냅·웨딩·프로필 등) | 3명 | 인스타그램 스냅 작가, 크몽·숨고 등록 작가 |

각 그룹에 20대·30대·40대 이상이 최소 1명씩 섞이도록 합니다.

### 모집 문구 (예시)

> 사진 모임 앱을 준비하고 있습니다. 출사 모임을 열어 보셨거나 참여해 보신 분께 30분 정도 경험을 여쭙고 싶습니다. 영상 통화 또는 카페에서 진행하고, 소정의 사례(커피 기프티콘)를 드립니다. 만드는 앱을 팔거나 가입을 권유하지 않습니다.

### 스크리닝 질문 (모집 시)

1. 최근 6개월 안에 사진 모임(출사, 동호회 정모)에 참여하거나 열어 본 적이 있나요?
2. 주로 어떤 카메라로 찍으시나요? (폰 / 미러리스·DSLR / 필름)
3. 사진으로 수익을 얻고 계신가요? (예 → 상업 작가 그룹)
4. 연령대를 알려 주세요.

## 3. 인터뷰 진행 (30~40분)

원칙: **과거의 실제 행동**을 묻습니다. "~하면 쓰시겠어요?" 같은 미래 가정 질문은 마지막 컨셉 반응 단계까지 하지 않습니다.

### 3-1. 시작 (3분)

- 녹음 동의 받기
- "정답은 없고, 실제 경험을 듣고 싶습니다. 제가 만드는 것에 대해 나쁘게 말해도 전혀 괜찮습니다."

### 3-2. 사진 생활 (5분)

1. 사진을 언제부터, 왜 찍기 시작하셨나요?
2. 요즘 한 달에 몇 번 정도 찍으러 나가세요? 주로 어디로?
3. 혼자 가는 편인가요, 같이 가는 편인가요? 그 이유는?

### 3-3. 출사 동행과 모임 (10분) → 가정 A, B

4. 가장 최근에 다른 사람과 같이 찍으러 간 날을 떠올려 주세요. 그 사람은 어떻게 알게 됐고, 그날은 어떻게 잡혔나요?
5. 같이 찍을 사람을 찾으려고 했는데 못 찾은 적이 있나요? 그때 어떻게 하셨어요?
6. 모임(동호회, 앱, 카페, 밴드)에 참여해 본 경험을 처음부터 말씀해 주세요. 어디서 찾았고, 신청은 어떻게 했고, 당일은 어땠나요?
7. 모임에 나가기 전에 가장 궁금했던 것은 무엇이었나요? (실력 차이, 나이, 분위기, 장비, 비용 등을 스스로 말하게 두고 유도하지 않기)
8. 모임에 나갔다가 "안 왔으면 좋았겠다" 싶었던 적이 있나요? 무엇 때문이었나요?
9. 모임을 안 나가게 된 계기가 있다면?

**운영자에게 추가**

10. 모임을 어디에 공지하고, 사람은 어떻게 모으세요? 공지부터 당일까지 가장 손이 많이 가는 일은?
11. 노쇼는 얼마나 있나요? 어떻게 대처하시나요?
12. 참여자 중 문제가 된 사람이 있었나요? (도촬, 매너, 안전) 어떻게 처리했나요?
13. 모임 운영에 돈을 쓰거나 받은 적이 있나요? (참가비, 장소비)

**상업 작가에게 추가**

14. 아마추어와 함께하는 모임(강의, 워크숍, 동행 출사)을 해 본 적이 있나요? 어떤 조건이면 다시 하시겠어요?
15. 같은 일을 하는 작가들과 정보(단가, 계약, 장비)를 어디서 나누세요? 부족한 점은?

### 3-4. 사진 공유와 피드백 (7분) → 가정 C

16. 찍은 사진을 어디에 올리세요? 올리고 나서 주로 어떤 반응을 받나요?
17. 내 사진에 대해 "이 부분이 이렇다"는 구체적인 말을 마지막으로 들은 게 언제였나요? 누구한테서?
18. 피드백을 받으려고 일부러 해 본 일이 있나요? (스터디, 카페 게시판, 지인에게 직접 물어보기) 결과는?
19. 다른 사람 사진에 피드백을 남겨 본 적이 있나요? 남기게 된 이유, 안 남기는 이유는?

### 3-5. 정보 습득 (3분)

20. 장비나 촬영법 정보를 어디서 얻으세요? 최근에 찾아본 것 하나만 말씀해 주세요.
21. "내 나이대·내 수준에는 안 맞는다"고 느낀 정보가 있었나요?

### 3-6. 컨셉 반응 (7분) — 마지막에만

와이어프레임(`../wireframes/index.html`)의 **모임 탐색 → 모임 상세** 화면을 보여 줍니다.

22. 이 화면을 보고 처음 든 생각을 말씀해 주세요. (설명하지 않고 기다리기)
23. 참여 신청을 누르기 전에 더 알고 싶은 정보가 있나요?
24. 여기서 모임을 여신다면 어떤 모임을 열겠어요? 어떤 사람은 안 왔으면 좋겠어요?
25. 지금 쓰는 방법(카페, 밴드, 지인) 대신 이걸 쓸 이유가 하나라도 있나요? 반대로 안 쓸 이유는?
26. (운영자) 첫 모임을 여기서 열어 달라고 부탁드리면 어떤 조건이 필요할까요?

### 3-7. 마무리 (2분)

27. 제가 안 여쭤봤지만 꼭 말하고 싶은 게 있나요?
28. 베타 테스트 초대를 드려도 될까요? 소개해 줄 만한 분이 있나요?

## 5. 인터뷰 후 정리 기준 (2주차 말)

15명을 마친 뒤 아래 표를 채우고 포지셔닝을 확정합니다.

| 가정 | 맞다 | 조건부 | 틀리다 | 결론 |
|---|---|---|---|---|
| A | | | | |
| B | | | | |
| C | | | | |

판단 기준

- 가정 A, B 중 하나라도 "맞다"가 참여자 7명 중 5명 미만이면 **모임 기능을 MVP 중심에 두는 것을 재검토**합니다.
- 가정 C가 약하면 피드백 게시판을 2단계로 미루고 MVP 개발 기간을 1~2주 줄입니다.
- 운영자 5명 중 3명 이상이 "첫 모임을 열어 주겠다"고 하면 창립 모임장 섭외를 바로 시작합니다.
- 컨셉 반응에서 반복해서 나온 "참여 전 알고 싶은 정보"는 모임 상세 화면(와이어프레임 4번)에 반영합니다.
